# Submarine Game

Submarine Game is a Unity submarine project built around a single player first-person movement, interactable submarine stations and combat with enemy ships and airplanes.

## Goals

- large navigable world map
- clear gameplay loop built around movement, missions, and submarine operation
- multiple functional submarine stations and control panels
- environmental systems such as fog, weather, and ocean conditions
- enemy ship AI capable of making decisions about formations and navigation
- multiple enemy ship models
- time traveling to skip long distance travels
- torpedo, drone and a missile system for the player submarine
